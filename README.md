# 🚕 taxi-helper

Калькулятор і аналізатор прибутковості поїздок у таксі **Uklon** (м. Вінниця).
Веде власний лог поїздок у `data.json`, рахує чистий прибуток з урахуванням газу (ГБО)
та комісій, і генерує **гарний HTML-звіт** із рекомендаціями «брати / думати / пропускати».

Проєкт також уміє **автоматично зчитувати скріншоти** архівних замовлень Uklon:
розпізнає адреси/суму/відстань (OCR через Apple Vision) і визначає **тип оплати за
кольором іконки** (🟡 готівка / 🔵 безготівка / 🟢 комбінована).

> 🌐 **Живий приклад звіту:** https://rinatyaushev.github.io/taxi-helper/
> (публікується автоматично з `main` через GitHub Pages — зручно відкрити з телефона
> й показати комусь).

---

## Навіщо це

У Вінниці короткі поїздки дають високий грн/км (працює базовий тариф), а довгі —
низький. Разом із дорогим газом це означає, що **головний вбивця прибутку — довгі
поїздки та «глухі кути»**. Інструмент рахує точні цифри й підказує поріг для рішення.

**Золоте правило** (рахується автоматично з налаштувань):
> Валова ціна поїздки має бути **≥ ~28 грн/км** (`сума ÷ відстань`), інакше не варто брати.

## Встановлення

```bash
npm install
```

- Node.js **22+** (запускає TypeScript напряму, без збірки)
- [jimp](https://github.com/jimp-dev/jimp) — аналіз кольору іконки оплати (чистий JS)
- **Swift** (macOS, вбудований) — OCR через Apple Vision (лише для обробки скрінів)

> HTML-звіт самодостатній (вбудовані стилі + трохи JS), без зовнішніх залежностей.

## Використання

### 1. Згенерувати HTML-звіт з поточних даних

```bash
npm run generate                     # data.json -> report.html
node src/generate.ts my.json out.html
```

Відкрий `report.html` у браузері: KPI-картки, золоте правило, налаштування Автопілота,
**сортована таблиця поїздок** із кольоровими бейджами та фільтрами (усі / бери / думай /
пропускай), пошуком, кнопкою **Завантажити → CSV / PDF**, зведенням по дистанції / зоні /
годині / оплаті та списком найгірших поїздок.

> 📄 Готовий приклад звіту лежить у [`examples/report.example.html`](./examples/report.example.html)
> — можна відкрити без запуску генератора, щоб побачити, як усе виглядає.

### 2. Швидкий аналіз у консолі

```bash
npm run analyze    # грн/км і чист/км по кожній поїздці
npm run report     # зведення по дистанції / зоні / годині / оплаті
```

### 3. Обробити нові скріншоти (macOS)

Поклади скріншоти архівних замовлень у `~/Desktop/screens` і запусти:

```bash
./pipeline.sh                       # або ./pipeline.sh /шлях/до/скрінів
```

Конвеєр зробить OCR, визначить тип оплати за кольором іконки, оновить `data.json`,
згенерує HTML-звіт і виведе аналіз.

> ⚠️ `npm run update-pay` **оновлює** тип оплати для вже наявних поїздок (за збігом
> дати/часу). Самі поїздки наразі додаються в `data.json` вручну на основі OCR-тексту
> (`/tmp/ocr.txt`).

## Формат даних (`data.json`)

```jsonc
{
  "settings": {
    "gas_consumption_l_100km": 13.5,   // витрата ГБО, л/100 км
    "gas_price_per_l": 43.6,           // ціна газу, грн/л
    "empty_run_coef": 0.5,             // частка порожнього пробігу від корисного км
    "commission_uklon_pct": 18,        // комісія Uklon, %
    "commission_cashless_pct": 2,      // +% за вивід безготівки
    "threshold_net_per_km": 14,        // поріг «доброї» поїздки, грн/км чистими
    "marginal_net_per_km": 10,         // нижче цього — «пропускай»
    "filters": { /* пороги для профілів Автопілота */ },
    "dead_end_areas": ["Стрижавка", "Зарванці", ...],
    "live_areas": ["Центр", "Вишенька", ...]
  },
  "trips": [
    {
      "datetime": "16.08 19:53",
      "payment": "Безготівка",         // Готівка | Безготівка | Комбінована
      "amount": 185,                   // сума, грн
      "distance": 6.23,                // відстань, км
      "from": "Зоряний Пров. (Агрономічне), 33",
      "to": "Анатолія Бортняка, 2",
      "zone": "Місто"                  // Місто | Глухий кут (за призначенням)
    }
  ]
}
```

### Логіка розрахунку
```
Паливо/км   = (витрата/100) × ціна_газу
Газ, грн    = відстань × (1 + коеф_порожняку) × Паливо/км
Комісія     = сума × 18%   (+2% якщо Безготівка)
Чистий, грн = сума − комісія − газ
```

## HTML-звіт (`report.html`)

| Секція | Що містить |
|---|---|
| **KPI-картки** | поїздок, виручка, чистий, чист/км, газ %, комісія % |
| **★ Золоте правило** | мін. валова ціна `≥ ~28 грн/км` та беззбитковість палива |
| **Автопілот** | 3 профілі рішення + готові значення й теги зон (глухі кути / живі) |
| **Поїздки** | сортована таблиця з `грн/км`, `чист/км`, бейджами **бери/думай/пропускай**, фільтрами, пошуком і кнопкою **Завантажити → CSV / PDF** |
| **Аналіз** | зведення по дистанції / зоні / годині / оплаті |
| **Найгірші 8** | кандидати на відсів |

## Структура репозиторію

| Файл | Призначення |
|---|---|
| `data.json` | усі дані: налаштування + поїздки |
| `src/types.ts` | типи (Trip, Settings, …) |
| `src/lib.ts` | спільні формули (`compute`, беззбитковість, золоте правило) |
| `src/generate.ts` | генератор HTML-звіту (самодостатній, без залежностей) |
| `src/analyze.ts` | швидкий per-trip аналіз у консоль |
| `src/report.ts` | категоризований звіт |
| `src/detectPay.ts` | визначення типу оплати за кольором іконки (jimp) |
| `src/updatePay.ts` | оновлення `payment` у `data.json` за скрінами |
| `ocr.swift` | OCR тексту скрінів (Apple Vision) |
| `ocr_boxes.swift` | OCR з координатами рядків |
| `pipeline.sh` | повний конвеєр обробки скрінів |
| `package.json` | залежності та npm-скрипти |
| `AGENTS.md` | контекст і правила для AI-агентів |
| `examples/` | приклад згенерованого HTML-звіту (`report.example.html`) |

Згенеровані `report.html`, `*.xlsx` та `node_modules/` в git не потрапляють (`.gitignore`).
