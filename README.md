# 🚕 taxi-helper

Калькулятор і аналізатор прибутковості поїздок у таксі **Uklon** (м. Вінниця).
Веде власний лог поїздок у `data.json`, рахує чистий прибуток з урахуванням газу (ГБО)
та комісій, і генерує Excel-калькулятор із рекомендаціями «брати / думати / пропускати».

Проєкт також уміє **автоматично зчитувати скріншоти** архівних замовлень Uklon:
розпізнає адреси/суму/відстань (OCR через Apple Vision) і визначає **тип оплати за
кольором іконки** (🟡 готівка / 🔵 безготівка / 🟢 комбінована).

---

## Навіщо це

У Вінниці короткі поїздки дають високий грн/км (працює базовий тариф), а довгі —
низький. Разом із дорогим газом це означає, що **головний вбивця прибутку — довгі
поїздки та «глухі кути»**. Інструмент рахує точні цифри й підказує поріг для рішення.

**Золоте правило** (рахується автоматично з налаштувань):
> Валова ціна поїздки має бути **≥ ~28 грн/км** (`сума ÷ відстань`), інакше не варто брати.

## Використання

### 1. Згенерувати Excel-калькулятор з поточних даних

```bash
python3 generate.py                 # data.json -> YYYY-MM-DD-result.xlsx
python3 generate.py my.json out.xlsx
```

### 2. Швидкий аналіз у консолі

```bash
python3 analyze.py    # грн/км і чист/км по кожній поїздці
python3 report.py     # зведення по дистанції / зоні / годині / оплаті
```

### 3. Обробити нові скріншоти (macOS)

Поклади скріншоти архівних замовлень у `~/Desktop/screens` і запусти:

```bash
./pipeline.sh                       # або ./pipeline.sh /шлях/до/скрінів
```

Конвеєр зробить OCR, визначить тип оплати за кольором іконки, оновить `data.json`,
згенерує Excel і виведе аналіз.

> ⚠️ `update_pay.py` **оновлює** тип оплати для вже наявних поїздок (за збігом
> дати/часу). Самі поїздки наразі додаються в `data.json` вручну на основі OCR-тексту
> (`/tmp/ocr.txt`).

## Формат даних (`data.json`)

```jsonc
{
  "settings": {
    "gas_consumption_l_100km": 13.5,   // витрата ГБО, л/100 км
    "gas_price_per_l": 43.6,           // ціна газу, грн/л
    "empty_run_coef": 0.5,             // частка порожнього пробігу від корисного км
    "commission_uklon_pct": 18,        // комісія Uklon, %
    "commission_cashless_pct": 2,      // +% за вивід безготівки
    "threshold_net_per_km": 14,        // поріг «доброї» поїздки, грн/км чистими
    "marginal_net_per_km": 10,         // нижче цього — «пропускай»
    "filters": { /* пороги для профілів Автопілота */ },
    "dead_end_areas": ["Стрижавка", "Зарванці", ...],
    "live_areas": ["Центр", "Вишенька", ...]
  },
  "trips": [
    {
      "datetime": "16.08 19:53",
      "payment": "Безготівка",         // Готівка | Безготівка | Комбінована
      "amount": 185,                   // сума, грн
      "distance": 6.23,                // відстань, км
      "from": "Зоряний Пров. (Агрономічне), 33",
      "to": "Анатолія Бортняка, 2",
      "zone": "Місто"                  // Місто | Глухий кут (за призначенням)
    }
  ]
}
```

### Логіка розрахунку
```
Паливо/км   = (витрата/100) × ціна_газу
Газ, грн    = відстань × (1 + коеф_порожняку) × Паливо/км
Комісія     = сума × 18%   (+2% якщо Безготівка)
Чистий, грн = сума − комісія − газ
```

## Excel-звіт (`*-result.xlsx`)

| Лист | Що містить |
|---|---|
| **Налаштування** | ставки, собівартість палива |
| **Поїздки** | усі поїздки + `грн/км`, `чист/км`, оцінка та підказка **бери/думай/пропускай** |
| **Аналіз** | зведення по оплаті, зоні, якості потоку |
| **Фільтри** | ★ золоте правило `≥28 грн/км`, 3 профілі й готові значення для Автопілота |
| **Інструкція** | як користуватись |

## Структура репозиторію

| Файл | Призначення |
|---|---|
| `data.json` | усі дані: налаштування + поїздки |
| `generate.py` | генератор Excel-калькулятора |
| `analyze.py` | швидкий per-trip аналіз у консоль |
| `report.py` | категоризований звіт |
| `ocr.swift` | OCR тексту скрінів (Apple Vision) |
| `ocr_boxes.swift` | OCR з координатами рядків |
| `detect_pay.py` | визначення типу оплати за кольором іконки |
| `update_pay.py` | оновлення `payment` у `data.json` за скрінами |
| `pipeline.sh` | повний конвеєр обробки скрінів |
| `requirements.txt` | Python-залежності |
| `AGENTS.md` | контекст і правила для AI-агентів |

Згенеровані `*.xlsx` в git не потрапляють (`.gitignore`).
