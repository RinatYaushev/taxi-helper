пушай# Приклади згенерованих звітів

Тут лежить **приклад** самодостатнього HTML-звіту, який створює `npm run generate`.

- [`report.example.html`](./report.example.html) — знімок звіту, зібраного з поточного `data.json`.

## Відкрити онлайн (з телефона)

Звіт публікується автоматично через **GitHub Pages** з кожним пушем у `main`:

**https://rinatyaushev.github.io/taxi-helper/**

Це постійне посилання — його зручно відкрити з телефона й показати комусь.
Публікацією керує воркфлоу [`.github/workflows/pages.yml`](../.github/workflows/pages.yml).

## Як згенерувати свій

```bash
npm run generate                       # data.json -> report.html (в корені, у git не коммітиться)
node src/generate.ts data.json examples/report.example.html   # оновити цей приклад
```

> Звичайний `report.html` у корені навмисно в `.gitignore` (похідний артефакт).
> Приклад тут має суфікс `.example`, тому не підпадає під ігнор і зберігається в репозиторії
> як демонстрація вигляду звіту (KPI-картки, «золоте правило», авто-інсайти, таблиця поїздок
> з фільтрами, пошуком і кнопкою **Завантажити → CSV / PDF**).
